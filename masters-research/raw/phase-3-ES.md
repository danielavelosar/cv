## D. FUSIÓN CON EL PERFIL INFORMÁTICO — el argumento estratégico

**El perfil "ingeniera de software que hace 3D y viene de la danza" ES el perfil TD/pipeline, y además es raro en laboratorios de control motor.** Desarrollo:

1. **TD/pipeline es su casa natural.** Los másteres C3 (URJC), C4 (U-tad Computación Gráfica) y C5 (UPC MIRI) **no piden portafolio artístico** — piden matemáticas + programación, que ella tiene de sobra. Su experiencia en sistemas multi-agente, FastAPI y ML se traduce directamente en *tools development* y automatización de pipeline. **Aquí su carencia (no tener book de escuela de arte) desaparece como problema.**

2. **Ventaja diferenciadora única — mocap + danza + biomecánica:** muy pocos ingenieros de gráficos entienden el movimiento desde dentro del cuerpo. La combinación **Rokoko (captura) + cuerpo entrenado de bailarina + base biomecánica** es exactamente lo que falta en:
   - laboratorios de **control motor/rehabilitación** (dominio 1): saben de sensores, les falta alguien que programe Y entienda cómo se mueve un cuerpo entrenado;
   - equipos de **animación/rigging** (dominio 2): un rigger/TD que entiende biomecánica real produce rigs y retargeting de mocap mucho mejores.
   Este cruce es su marca personal — explótalo en la carta de motivación y el TFM.

3. **Proyectos a construir YA (antes de postular, para compensar la falta de book/experiencia):**
   - Pipeline de mocap con Rokoko → retargeting a rig en Blender, documentado en GitHub (demuestra pipeline + código + movimiento).
   - Herramienta Python que analice datos de captura (ángulos articulares, comparación con patrones de danza) — une ML + biomecánica.
   - Visualización web (SvelteKit) de datos de movimiento — une su stack dev con el dominio cuerpo.
   - Un rig facial o corporal con scripting propio → mini-reel técnico (no artístico) que abre las puertas de C3/C4/C5.
   - Vincular con su investigación previa de accesibilidad de parques (Kennedy): análisis de movilidad/marcha en espacio público → conecta accesibilidad + biomecánica + datos.

4. **Ángulo de tesis (TFM) que la unifica:** *"Captura y análisis de movimiento para accesibilidad / rehabilitación"* — p. ej. usar mocap de bajo costo (Rokoko) para evaluar patrones de marcha en entornos urbanos accesibles, o retargeting biomecánicamente informado. Cabe en URJC (animación/simulación aplicada), UPC MIRI (investigación en gráficos+movimiento), IBV/UPM (valoración del movimiento). **Este TFM es el puente entre sus 4 prioridades: impacto en personas + creación visual + técnica + cuerpo/mundo.**
